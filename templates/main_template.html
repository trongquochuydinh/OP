Chart Plotter

Step 1: Select Data Source and Range

Use Desktop: Select Files for normal workflow. Manual path entry auto-loads on change or Enter.
Plotting logic: 1 column = frequency chart; 2 columns = first is X, second is Y (unless "Count row occurrences" is checked — then one bar per distinct pair); 3+ columns = first is shared category and the rest are separate series (with counts checked: non-null counts per category per series). Dumbbell chart: use 2 columns for category + low value only, or 3 columns for category, low, and high (extra columns are ignored).
Range formats: A2:C10 (data subset), A (column), A:C (columns range), B,D (non-neighboring full columns)
Column names: After "Preview Range", type a name for each column in the empty header row above the data.
